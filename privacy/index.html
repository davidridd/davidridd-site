privacy.

The short version is that this site doesn’t track you.

On this site

No cookies, no analytics, no advertising, and no scripts from anyone else. The typeface and the images are served from davidridd.com itself, so a visit here is not reported to any third party.

Hosting

The site is hosted on GitHub Pages. GitHub logs visitors’ IP addresses for security purposes, as described in GitHub’s documentation and its privacy statement. I don’t see those logs.

If you email me

An email or an application comes to my inbox and stays there so I can reply and, if we work together, keep track of the project. I don’t sell it, share it, or add you to a list. Ask and I’ll delete it.

Booking a call

The free consult is scheduled through Calendly, which has its own privacy policy. Links to Amazon, Fiverr, LinkedIn, Instagram, and Substack go to those sites, and their policies apply there.

Questions

Write to davidriddwriting@gmail.com.
